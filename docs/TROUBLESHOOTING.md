# Industrial Troubleshooting & Diagnostic Guide

This runbook contains 28 detailed diagnostic procedures covering hardware failures, electrical wiring faults, serial link loss, wireless telemetry drops, audio playback errors, memory pressure, and security lockout states.

---

## Comprehensive Diagnostic Matrix (28 Scenarios)

| # | Subsystem | Symptom | Probable Root Cause | Diagnostic CLI Command | Step-by-Step Remediation |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **1** | Interlock | State shows `SAFE-NO-HARDWARE` on startup | GPIO chip or pin offsets set to `null` in `/etc/smart-water/config.yaml` | `python -m app.cli test-relay` or `cat /etc/smart-water/config.yaml` | Complete the 7-step Setup Wizard or edit `config.yaml` with valid GPIO chip path (`/dev/gpiochip1`) and line offsets. |
| **2** | Interlock | Status reports `WIRING FAULT` alarm | Impossible interlock state: `interlock_out` is HIGH while `interlock_mid` is LOW | `gpioget gpiochip1 <mid_pin> <out_pin>` | Inspect float wiring. Verify that the tap wire to IN3 is connected between Full float and Sump float, and not swapped. |
| **3** | Interlock | Motor refuses to start: `Overhead tank is already full` | Full float reed switch open or float is stuck at upper limit | `gpioget gpiochip1 <out_pin> <mid_pin>` | Check overhead tank water level. If tank is not full, inspect float mechanism for debris or mineral encrustation. |
| **4** | Interlock | Motor refuses to start: `Source sump is empty` | Sump float reed switch open (dry sump or low ground water) | `gpioget gpiochip1 <out_pin> <mid_pin>` | Verify physical water level in source well/sump. Check float buoyancy and continuity across switch contacts. |
| **5** | Interlock | Main AC motor trips after exactly 15 minutes | Continuous motor max-runtime limit exceeded (`max_runtime_s: 900`) | `journalctl -u smart-water -n 50 \| grep MOTOR_MAX_RUNTIME` | Inspect tank for leaks or airlocks in main delivery pipe preventing tank from filling within 15 min. Wait 30m cooldown then reset. |
| **6** | Interlock | Motor start rejected: `Motor is cooling down` | Mandatory cooldown window active following a max runtime trip | `curl -H "Authorization: Bearer $T" http://localhost:8000/api/telemetry/live` | Cooldown timer protects the submersible pump winding. Wait until cooldown expires or execute emergency cooldown override in config. |
| **7** | Interlock | Motor start rejected: `Manual reset required via UI/API` | Operator has not cleared the lockout flag after cooldown expiry | `curl -X POST -H "Authorization: Bearer $T" http://localhost:8000/api/motor/reset` | Trigger `/api/motor/reset` endpoint or click "Reset Lockout" in the Web UI dashboard. |
| **8** | Hardware | Motor start rejected: `Leak sensor is tripped` | IN4 conductive pad detected water bridging contacts | `gpioget gpiochip1 <leak_pin>` | Inspect manifold and pump housing for burst pipes or hose leaks. Dry sensor probe contacts thoroughly. |
| **9** | Gateway | Status reports `LINK LOST` to Garden Gateway | USB cable disconnected, loose hub port, or missing udev symlink | `ls -l /dev/garden-gateway` or `dmesg \| grep -i tty` | Reseat USB cable. Verify `/etc/udev/rules.d/99-smart-water.rules` matches ESP32 VID:PID using `lsusb`. Run `udevadm trigger`. |
| **10** | Gateway | Error in logs: `Permission denied: /dev/garden-gateway` | User `smartwater` is not in the `dialout` system group | `groups smartwater` or `id smartwater` | Run `sudo usermod -aG dialout smartwater` and restart service: `sudo systemctl restart smart-water`. |
| **11** | Gateway | ESP-NOW packets not arriving from Node | Node and Gateway configured on different Wi-Fi channels | PlatformIO `ESPNOW_WIFI_CHANNEL` in `config.h` | Ensure both Gateway and Node firmware have identical `ESPNOW_WIFI_CHANNEL` (default channel 1). Re-flash if mismatched. |
| **12** | Telemetry | Garden data marked `STALE (>90s)` | Node out of RF range, battery dead, or solar brownout | `journalctl -u smart-water -f \| grep garden` | Check 12V battery voltage on garden node. Move node closer or fit an external dipole antenna to ESP32-C3 IPEX connector. |
| **13** | Telemetry | Head-end data marked `STALE (>15s)` | PC817 driver thread hung or GPIO chip polled unsuccessfully | `systemctl status smart-water` | Check journal for libgpiod character device errors. Verify `/dev/gpiochip1` accessibility. |
| **14** | Plant | Irrigation rejected: `Probe voltage outside sanity band` | Capacitive soil probe unplugged, shorted, or disconnected | `curl -H "Authorization: Bearer $T" http://localhost:8000/api/telemetry/live` | Inspect probe wiring to ADS1115. A disconnected probe floats above 3.0V or shorted to ground below 0.5V. |
| **15** | Plant | Irrigation rejected: `Probe is uncalibrated` | Dry/wet reference voltages are null in `/etc/smart-water/config.yaml` | `cat /etc/smart-water/config.yaml \| grep calibration -A 5` | Run the two-step calibration wizard: immerse probe in air for dry calibration, then in cup of water for wet calibration. |
| **16** | Plant | Irrigation rejected: `Irrigation reservoir is dry` | Reservoir reed float switch is open (`reservoir_wet: false`) | `curl -H "Authorization: Bearer $T" http://localhost:8000/api/telemetry/live` | Refill drip reservoir tank with water. Check float switch continuity across GPIO 3. |
| **17** | Plant | Irrigation rejected: `System clock is invalid (un-synced)` | System time is earlier than firmware build date epoch; no RTC/NTP | `timedatectl status` or `hwclock -r` | Ensure DS3231 RTC coin cell (CR2032) is good. Check I2C RTC detected at `0x68` using `i2cdetect -y 7`. Set system clock. |
| **18** | Plant | Pump shut off with `NO FLOW DETECTED after 10s` | Zone 1 pulse flow meter registered fewer than `min_pulses_10s` (4 pulses) | `curl -H "Authorization: Bearer $T" http://localhost:8000/api/telemetry/live` | Check for clogged drip emitters, kinked tubing, closed ball valve, or airlock in Zone 1 pump impeller. |
| **19** | Plant | Pump run limited to exactly 60 seconds | Server and ESP32 firmware hard cap enforces max 60s per pulse | `grep MAX_PUMP_HARD_TIMEOUT_S firmware/node/include/config.h` | By design. Long runs are executed in distinct pulses separated by soak periods to avoid root drowning and battery drain. |
| **20** | Audio | Voice alerts silent or error: `aplay: test: No such device` | CM108 USB audio interface missing or ALSA card index shifted | `aplay -l` or `cat /proc/asound/cards` | Re-insert CM108 audio adapter. Run `amixer -c <card> sset 'Headphone' 80% unmute`. Check `audio.alsa_device` in `config.yaml`. |
| **21** | Audio | Voice alerts silent between 22:00 and 06:00 | Quiet hours active (`quiet_hours_enabled: true`) | `grep quiet_hours /etc/smart-water/config.yaml -A 5` | By design. Low-priority speech is silenced at night. Critical Priority 0 alerts (leak, fire, lockout) always sound. |
| **22** | Audio | Espeak fails with `espeak-ng: command not found` | Package `espeak-ng` was not installed during provisioning | `which espeak-ng` | Run `sudo apt-get install -y espeak-ng alsa-utils`. |
| **23** | System | Service crashes with `Memory limit exceeded (35M)` | Systemd cgroup killed process due to memory leak or buffering | `systemctl status smart-water.service \| grep Memory` | Verify SQLite PRAGMA cache limits (`cache_size = -2000`). Confirm SSE stream connections are disconnecting cleanly. |
| **24** | System | Kernel Watchdog reboots board after 15 seconds | Application event loop blocked or CPU starved for >15s | `dmesg \| grep -i watchdog` | Check for blocking sync I/O in custom rules. Ensure `/dev/watchdog` ping interval is 5s (`watchdog.py`). |
| **25** | Network | Refuses to start with `Refusing to bind to 0.0.0.0` | Security policy forbids binding public IP without explicit flag | `grep bind_address /etc/smart-water/config.yaml` | Set `bind_address` to your private Tailscale mesh IP (e.g., `100.x.y.z`) or set `allow_all_interfaces: true` if behind NAT. |
| **26** | Security | API requests fail with `401 Unauthorized` | Missing or invalid Bearer token in request header | `python -m app.cli show-token` | Copy your token from `/etc/smart-water/.auth_token_hash` setup step or run `python -m app.cli rotate-token` to generate fresh token. |
| **27** | Database | SQLite database locked (`database is locked`) | Concurrency contention or missing WAL mode | `sqlite3 /var/lib/smart-water/state.db "PRAGMA journal_mode;"` | Verify WAL mode is active (`PRAGMA journal_mode=WAL`). Increase busy timeout if disk I/O on micro-SD card is slow. |
| **28** | I2C | I2C devices missing from bus 7 (`i2cdetect -y 7` shows empty) | Radxa device tree overlay for I2C7 not enabled in `/boot/armbianEnv.txt` | `i2cdetect -y 7` | Add `overlays=i2c7` to `/boot/armbianEnv.txt` (or `/boot/uEnv.txt`) and reboot the ROCK Pi S. |
